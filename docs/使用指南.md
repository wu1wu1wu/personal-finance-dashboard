# 使用指南

## 这是什么

一个**只装在自己设备上**的记账本。

它从你的微信、支付宝账单和支付通知里把交易捞出来，自动分类、自动算账、自动管预算。

- 没有账号、不用登录、**数据不上传**，全都存在你自己的手机/电脑里
- 既能当网页用，也能装成安卓 App（装法见下方「装到手机上」）
- 一句话：它不替你花钱，只负责把花掉的钱记清楚、看明白

---

## 三步上手

### 第一步：导入历史账单（一次性，最值得做的一步）

**微信**：我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→ 下载账单 → 选「用于个人对账」→ 邮箱会收到一个 CSV
**支付宝**：我的 → 账单 → 右上角「⋯」→ 开具交易流水证明 → 选「用于个人对账」→ 收到的是**压缩包，要先解压**，里面才是 CSV

然后打开 App → 底部「明细」→ 上传区 → 选文件。

导入后它会自己干完这些事：认出是微信还是支付宝、跳过重复的记录、给每笔分好类、并把之前只记到金额的老记录补上商户名和商品。

> 导出频率随意，一个月一次甚至更久都行，补全不依赖你导得多勤。

### 第二步：让它以后自己记账（安卓，可选但省事）

设置 → 自动记账 → 打开「通知使用权」（这一步必须在系统设置里手动开，App 没法代开）。
再把 App 的省电策略设为「不限制」、允许自启动，否则系统会把监听服务杀掉。

之后你每付一笔钱，它自动记一笔，不用管。

### 第三步：平时就看四个页面

| 页面 | 用来干什么 |
|---|---|
| **看板** | 这个月花了多少、钱花在哪几类、趋势怎么走；顶部能切「手记」视图 |
| **明细** | 每一笔的流水。点一行看详情，能改金额、时间、商户、备注，也能改分类、删掉 |
| **手记** | 想留住的消费，写一句话、配一张图，就在看板里铺成一张大卡片（点卡片上的字就能改） |
| **预算** | 给分类定上限，花到 80% 变黄、超了变红 |
| **报告** | 一个月一页总结：环比、要点、分类 TOP5、每日支出；右上角可一键复制文字 |
| **设置** | 账单导入、外观与语言、自动记账、分类规则、数据管理（备份/恢复/清空） |

### 装到手机上（可选）

- **不装 App**：用浏览器打开，选「添加到主屏幕」，装好后全屏打开、断网也能用
- **装 App**：把 `android/app/build/outputs/apk/debug/app-debug.apk` 传到手机安装即可

## 分类是怎么定的（重点）

一笔交易该归到哪一类，按下面的顺序找答案，**前面的说了算**：

### 1. 你自己定的（优先级最高）

「设置 → 分类规则」里你手写的关键词规则，以及**你改分类改满 3 次后它自动记住的规则**。

### 2. 内置关键词表

就是「美团 → 餐饮、滴滴 → 交通」这种常见商户词表。

这里要说明一件事：这张表里**有一部分词是照着你自己的账单加的**，比如 `池奈` `詹记` `姜胖胖` `仟吉` `塔斯汀` `古茗` `驴充充` `佳源科技` —— 它们不是通用词，是你账单里真实出现过的店。所以它认识你的常去店铺，不认识的新店就要靠第 1 层或第 3 层。

### 3. 你自己的消费习惯

它只拿**带真实商户的历史账单**做统计（不看自己猜的记录，免得越猜越错），算出「金额区间 + 时段 → 分类」的规律。

比如你晚上 20–50 元的消费几乎都是餐饮，那下次来一条只有金额的通知，它就按餐饮记，并打上「**推测**」标记让你一眼看出这是猜的。

它只在**样本 ≥ 5 笔、且最热门分类占比 ≥ 70%** 时才开口，不够格就什么都不说。

### 兜底：都不命中 → 「待确认」

**它绝不瞎填。** 认不出来就老实放在「待确认」里等你归类，看板上有入口，点进去一键批量处理。

### 分类错了怎么纠正

在**明细里点那笔的分类标签，直接改成对的**就行。

- 改满 3 次同类，它会自动生成一条规则，以后一直按你的来
- 也可以提前在「设置 → 分类规则」里手写关键词，直接压过内置词表

### 为什么偶尔还是会认错

关键词匹配的固有局限，主要有三种：

1. **新商户**：没见过就是没见过，落到「待确认」
2. **店名只有店招**：微信账单里商户名常常只写「武汉市某某点心店」，没有业态信息
3. **一个词有歧义**：比如「抖音」可能是购物也可能是外卖，「充电」可能是充电桩也可能是充电宝

这类错判只能靠你纠正几次，它就会学会。

## 记住这几件事

- **微信通知里没有商户名**，这是微信的设计（通知内容只有「已支付 ¥23.00」），任何 App 都拿不到。导入账单就能补全
- **数据只在本机**，不跨设备同步。换手机或重装前，先「设置 → 数据管理 → 导出备份」存一份 JSON
- **删错了能撤销**：删完底部会留一条「撤销」；设置 → 数据管理 → 「最近删除」保留 30 天
- **支付宝账单要先解压**，应用只读里面的 CSV
- **上架商店需要另配签名**，仓库里的 APK 是调试签名，自己装没问题
