# 使用指南

## 这是什么

一个**只装在自己设备上**的记账本。

它从你的微信、支付宝账单和支付通知里把交易捞出来，自动分类、自动算账、自动管预算。

- 没有账号、不用登录、**数据不上传**，全都存在你自己的手机/电脑里
- 既能当网页用，也能装成安卓 App（装法见下方「装到手机上」）
- 一句话：它不替你花钱，只负责把花掉的钱记清楚、看明白

---

## 三步上手

### 第一步：导入历史账单（一次性，最值得做的一步）

**微信**：我 → 服务 → 钱包 → 账单 → 右上角「常见问题」→ 下载账单 → 选「用于个人对账」→ 邮箱会收到一个 CSV
**支付宝**：我的 → 账单 → 右上角「⋯」→ 开具交易流水证明 → 选「用于个人对账」→ 收到的是**压缩包，要先解压**，里面才是 CSV

然后打开 App → 底部「明细」→ 上传区 → 选文件。

导入后它会自己干完这些事：认出是微信还是支付宝、跳过重复的记录、给每笔分好类、并把之前只记到金额的老记录补上商户名和商品。

> 导出频率随意，一个月一次甚至更久都行，补全不依赖你导得多勤。

### 第二步：让它以后自己记账（安卓，可选但省事）

设置 → 自动记账 → 打开「通知使用权」（这一步必须在系统设置里手动开，App 没法代开）。
再把 App 的省电策略设为「不限制」、允许自启动，否则系统会把监听服务杀掉。

之后你每付一笔钱，它自动记一笔，不用管。

### 第三步：平时就看四个页面

| 页面 | 用来干什么 |
|---|---|
| **看板** | 这个月花了多少、钱花在哪几类、趋势怎么走；顶部能切「手记」视图 |
| **明细** | 每一笔的流水。点一行看详情，能改金额、时间、商户、备注，也能改分类、删掉 |
| **手记** | 想留住的消费，写一句话、配一张图，就在看板里铺成一张大卡片（点卡片上的字就能改） |
| **预算** | 给分类定上限，花到 80% 变黄、超了变红 |
| **报告** | 一个月一页总结：环比、要点、分类 TOP5、每日支出；右上角可一键复制文字 |
| **设置** | 账单导入、外观与语言、自动记账、分类规则、数据管理（备份/恢复/清空） |

### 装到手机上（可选）

- **不装 App**：用浏览器打开，选「添加到主屏幕」，装好后全屏打开、断网也能用
- **装 App**：把 `android/app/build/outputs/apk/debug/app-debug.apk` 传到手机安装即可

## 分类是怎么定的（重点）

一笔交易该归到哪一类，按下面的顺序找答案，**前面的说了算，命中一条就不再往下走**。

### 1. 你设的

你手动改过的分类，它永远不会再动——这是唯一有「否决权」的一层。

### 2. 转账与收入

转账、红包、提现、退款、还款、零钱通 → 「**转账**」；剩下的只要**金额是负的**（钱进来了）→ 「**收入**」。

工资、理赔到账这类进账都归「收入」，不再被迫混进支出。转账和收入都不计入支出统计与分类饼图。

### 3. 认得这家店（商户记忆）

它先从账单的「商品说明」里把店名抠出来：`塔斯汀·中国汉堡（武汉宁康路店）-美团App-****218` 认成 `塔斯汀`，渠道名、订单号、分店后缀都先剥掉。

然后照你以前给这家店定的分类走。**如果你给同一家店定过两种分类，它就不猜了**，直接放「待确认」——宁可多问你一次，也不替你做主。

### 4. 品类关键词

就是「星巴克 → 餐饮、滴滴 → 交通」这种词表。命中多个时**最长的词优先**，其次看优先级，最后看谁在文本里先出现。

平台名（美团、淘宝、抖音……）**不算品类词**，交给下一层单独判断。以前「美团」抢走一切、把所有单子都推成餐饮，就是这么来的。

这一层还有一条规矩：词表里的一部分词是照着你自己的账单加的，比如 `池奈` `詹记` `姜胖胖` `仟吉` `塔斯汀` `古茗` `驴充充` `佳源科技` —— 它们不是通用词，是你账单里真实出现过的店。所以它认识你的常去店铺，不认识的新店就要靠你教。

### 5. 平台

- **淘宝、拼多多、天猫、京东、唯品会、苏宁**：在它上面下单本来就是买东西，直接算「购物消费」。这是平台的性质，不是猜。
- **美团、饿了么、抖音、高德**：同一个平台什么都能买。只有这条渠道**有 3 条以上你确认过的记录、且其中 80% 以上是同一类**时，它才给一个「推测」；不够格就继续往下走。

### 6. 时段 + 金额（只用在没有商户的记录上）

支付通知里只有金额和时间，没有店名。它会从你确认过的记录里学：**样本 ≥5 条、同一类占 ≥80%** 才算数。

比如在你的数据里学出来的是「15~25 元 且 10:00–21:00 → 餐饮」，12 条支持、83% 纯度。所以一条 22 元的中午通知会被记成餐饮，并打上「**推测**」。

有店名的记录不走这一层：`16:23 / 15.8 元` 是美团单车，不能因为金额落在区间里就当餐饮。

### 兜底：「待确认」

以上都不成立 → 放进「**待确认**」。

**这不是 bug，是它老实的地方。** 认不出来就留白，比猜一个「餐饮美食」塞进去干净得多：猜错了你根本发现不了，留白了你一眼就能看见。看板上有「待确认」入口，点进去可以一条条或批量归类。

### 「推测」是什么意思

「推测」= 按你历史数据的比例猜的，可能八成对，也可能不对。

它和「确定」的区别是：确定有明确依据（你设的 / 这家店 / 这个词 / 这个平台 / 金额为负），推测只有一句「以前多半是这样」。

点开详情能看到「**分类依据：…**」，写着它凭什么这么判（改动之前就分好类的老记录没有这行）。

### 分类错了怎么纠正（顺手就教会它了）

- **在明细里把分类改一次**，这家店就记住了：下次同一个商户直接按你改的来，不用再改
- **改满 3 次同类**，还会自动生成一条关键词规则
- 想一次覆盖一批词，去「**设置 → 分类规则**」里自己加关键词，它压过内置词表
- 给同一个商户定过两种分类时，它会留白让你再确认，而不是自己投票

### 为什么偶尔还是会认错

关键词匹配的固有局限，主要有三种：

1. **新商户**：没见过就是没见过，落到「待确认」
2. **店名只有店招**：微信账单里商户名常常只写「武汉市某某点心店」，没有业态信息
3. **一个词有歧义**：比如「充电」可能是充电桩也可能是充电宝

这类错判只能靠你纠正几次，它就会学会。

## 记住这几件事

- **微信通知里没有商户名**，这是微信的设计（通知内容只有「已支付 ¥23.00」），任何 App 都拿不到。导入账单就能补全
- **数据只在本机**，不跨设备同步。换手机或重装前，先「设置 → 数据管理 → 导出备份」存一份 JSON
  - 手机上点导出会**弹出系统分享面板**：选「保存到文件」就存进手机，也可以直接发给自己
- **删错了能撤销**：删完底部会留一条「撤销」；设置 → 数据管理 → 「最近删除」保留 30 天
- **支付宝账单要先解压**，应用只读里面的 CSV
- **上架商店需要另配签名**，仓库里的 APK 是调试签名，自己装没问题
